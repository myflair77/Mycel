# 보안 기준
현재 앱은 정적 UI로 개인정보/비밀번호/대화를 수집하지 않는다. Google Fonts 요청은 발생할 수 있으며 운영 전 자체 호스팅을 검토한다.

운영 전: 검증된 인증 제공자, HTTPS, 서버 권한 검사, 방 비참여자 차단, 매개변수 쿼리, 입력 검증, 속도 제한, 초대 만료, 비공개 첨부파일과 크기/확장자/실제 형식 검증, 비밀정보 분리.

React 기본 텍스트 렌더링 유지; 임의 HTML 렌더링 금지. VITE_*에는 비밀키 금지.
E2EE 미지원. 운영자가 기술적으로 내용을 열람 가능한 설계임을 서비스에 고지해야 한다. 보존/탈퇴/백업 정책 및 법적 검토는 베타 전 별도 수행.
