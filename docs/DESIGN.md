# 디자인 기준
2026-11-13 사용자 제공 Apple Style Reference를 기준으로 채택.
원문: DESIGN_REFERENCE.md

메신저 UI에 적용: 흰색/연회색 표면, #1d1d1f 글자, 얇은 구분선, #0066cc 링크, 28px 둥근 표면, 그림자/그라디언트 없음.
광고용 80px 제목을 앱 내부에 그대로 사용하지 않고 가용 폭에 맞게 32–64px로 조정. 세 패널/모바일 단일 패널 구조 유지.
Apple 로고/제품 사진을 사용하지 않고 독자 메신저 구성 유지.
시스템 글꼴을 사용하며 SF 폰트 파일을 배포하거나 외부 폰트를 요청하지 않는다.
다크 모드는 동일한 중립 색상 체계로 해석. 표시 이름은 계속 미정.
