## 2026-11-14: 대용량과 UI 방향
- 신규 R2 첨부 상한 300MiB, 4MiB 분할 유지. 실제 서비스 경로 검증과 로컬 모의 검증을 구분한다.
- 읽음은 1:1 미확인 인원 숫자, 시간은 말풍선 중앙 방향 하단. 글자 크기는 1%씩 기기별 조절.
- 카카오톡을 참고한 UI 개편 제안은 docs/UI-UX-REVIEW.md. 기존 Apple 계열 색/여백을 유지하며 대화 우선 구조를 권장한다. 전면 개편은 아직 적용하지 않는다.

## 2026-11-14: UI·UX 개선안 실행
- 대화·친구·설정의 정보 구조를 분리하고 실제 창 폭과 visualViewport 높이에 맞춘다. 강제 모드라도 744px 미만은 입력 공간 보호를 위해 1열.
- 초안/고정/입력 환경은 브라우저 단위. 원격 회원·대화·첨부 데이터 구조는 유지한다.
- 미완료 R2 업로드 취소 API만 추가. 전송 완료 원본을 취소로 삭제하지 않는다. 다중 파일은 최대 10개 선택, 순차 전송.
- 별도 창은 사용자의 클릭으로 열고 이름으로 재사용. 작업표시줄 그룹·항상 위 배치는 브라우저/OS 정책에 따른다.
- 수정/삭제·그룹 채팅·AI 연결과 닫힌 기기 배지 동기화는 원래 개선안의 별도 후속 단계이며 이번 UI 개편에 포함하지 않는다.


## 2026-11-14 화면 개편
밝은 디자인, 친구 검색/목록 중심 배치, 상단 요청·차단 관리, 목록 옆 새로 고침 적용. 검색 제한 안내는 제목 옆 버튼과 바깥 클릭/Escape로 닫히는 팝오버. 테마는 설정에서 라이트/다크/시스템 선택하고 저장. 글자 크기는 기존 localStorage 저장 키를 유지하며 재시작 시 복원(사이트 데이터 삭제 시 초기화).

상단 화면 모드는 접근성 이름을 유지한 드롭다운만 표시하며 좌우 설명은 제거.
## 2026-11-14 계정 설정
대화와 친구는 영구 UUID로 유지한다. 프로필 DB가 닉네임/아이디의 원본이며 Auth metadata는 호환을 위해 서버 RPC에서 함께 갱신한다. 이메일과 비밀번호는 Supabase Auth만 관리한다. 복구는 최초 가입 주소가 아닌 현재 인증 주소 기준. 이메일을 잃은 계정의 무인 복구는 제공하지 않는다. 로그인은 계속 이메일 기반이며 ID찾기는 보조 기능이다. 민감한 변경 실계정 테스트는 사용자 입력으로 진행한다.

2026-11-14: 친구 검색 이용 안내 버튼을 정보 아이콘+둥근 보조 버튼으로 정리. 네이티브 회색 테두리 제거, hover/open/focus 및 다크 테마 대응. 안내 팝오버는 제한별 행과 재요청 안내로 구성.
2026-11-14: 계정 버튼은 부드러운 보조 버튼, 파란 저장 버튼, 붉은 차단 버튼으로 역할을 구분한다.
2026-11-14: 앱 설치 이벤트는 단일 InstallGuideHost에서 수신해 상단/설정 중복 설치 프롬프트를 방지. Edge 모바일은 Chrome 재접속을 우선 안내하고 Edge 설치 버튼은 제공하지 않음. 설치 가이드는 모달로 작은 화면에서도 스크롤 가능.
2026-11-14: 초대 링크는 친구 요청 권한의 우회 수단이 아니다. 생성자 수락은 유지하고 자동 친구 추가하지 않는다. 링크는 7일 다중 이용, 필요시 생성자가 폐기. 신규 가입 서버 복원과 기존 로그인 링크 컨텍스트를 함께 사용하며 토큰만으로 계정 접근은 불가.

2026-11-15: 수정/전체 삭제는 작성자 24시간(나와의 대화 제외), 숨김/중요는 계정별. 전달 파일은 기존 원본과 만료일 재사용. 게시판 첨부는 대화 파일에서 선택하며 게시글 삭제 시 원본 파일을 삭제하지 않음. 검색어가 있을 때만 우측 × 표시.

2026-11-15: 공유 수신은 전송 확정 전 기기 임시 저장만 사용. 원본 파일 외부 공유는 인증된 다운로드 후 파일 바이트로 전달하며 내부 인증 URL은 노출하지 않음. 수신 파일은 기존 R2 업로드·30일 보관 정책 재사용. 실패 시 같은 계정·대화·UUID를 유지하고, 완료/취소 또는 24시간 만료 후 저장소 접근 시 임시 자료 정리. 외부 앱별 공유 한도는 300MB 대화 첨부 한도와 별도.


## 2026-11-15 — 협업 공간과 자료 보존
- 일반 대화는 독립 유지. 공간은 기존 팀 권한 모델에 연결된 방 1개와 공간 메타데이터로 구성한다.
- 대화 탭은 공간 채팅의 동일 방을 모아 보는 진입점이다. 채팅·읽음·알림 원본을 복제하지 않는다.
- 새 공간 자료는 공간 소유. 관리자 관리권, 작성자 편집, 다른 참여자 보기/댓글이 기본이며 관리자가 전체 편집을 허용할 수 있다.
- 신규 참여자는 현재 공간 자료를 보되 과거 수정 이력은 첫 접근 이후로 제한한다. 일반 공유 원본은 기존 대화 참여 시점 공개 범위를 유지한다.
- 개인 자료를 공유할 때 공간에 독립 복사가 권장 기본이며 원본 연결 공유는 명시적 선택이다.
- 일정, 노트, 댓글, 수정 이력, 휴지통에는 만료 일자나 정리 작업을 만들지 않는다. 기존 파일 만료 정책은 변경하지 않는다.
