# 검증 계획
## 0단계
TypeScript check, production build, dev HTTP 200. 데스크톱/모바일 시각 검증과 실제 브라우저 기능 검증 여부를 STATUS에 별도로 기록.

## 선행 백엔드 실험
독립 계정 A/B로 로그인 → 방 생성 → A 저장 성공 → B 이벤트 수신 → DB 직접 확인 → 새로고침 기록 보존 → B 연결 종료 중 전송 → 재연결 순번 복구 → 같은 키 재전송 단일 행 → 다른 방/비회원 C 접근 거절.
WebSocket upgrade 성공과 여러 인스턴스/방의 팬아웃 성공을 따로 검증. 게시 URL 검증은 배포 승인 후 수행.

## 이후 단계
친구 수락/취소/차단 양쪽 일관성, 그룹 A/B/C 및 방장 이양, 첨부파일 비참여자 접근 거절, 페이지 조회 경계, 메시지 수정/삭제, 다른 기기 기록 복원. Vitest로 도메인 규칙, Playwright로 실제 계정 통합 검증 예정.
